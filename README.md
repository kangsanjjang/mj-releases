# MJ 시리즈 배포본

Windows용 MJ 프로그램의 포터블 실행 파일을 받는 곳입니다. 소스 코드는 여기 없습니다.

| 프로그램 | 설명 | 받기 |
|---|---|---|
| MJ DownLoader | YouTube 다운로드 | [최신 릴리즈 목록](https://github.com/kangsanjjang/mj-releases/releases) 에서 `downloader-v…` |
| MJ Player | 동영상 플레이어 | `player-v…` |
| MJ MarkDown | Markdown 뷰어·편집기 | `markdown-v…` |

## 사용법
1. [Releases](https://github.com/kangsanjjang/mj-releases/releases)에서 원하는 프로그램의 zip을 받습니다 (Assets 칸).
2. 원하는 폴더에 풀고 폴더 안의 exe를 실행합니다. 설치가 필요 없습니다.
3. 새 버전이 나오면 프로그램이 알려 주고, 버튼 한 번으로 업데이트합니다 (업데이트 기능이 들어간 버전부터).

요구 사항: Windows 10/11 64비트
